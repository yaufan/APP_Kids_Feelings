# 設計：心情小屋

> 給 2～5 歲小朋友的心情遊戲（認識心情、說出心情、讓自己冷靜下來）。2026-11-15 定案（見最後「已經決定的事」）。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」「小小生活家」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 一句話
小朋友和一朵會變心情的雲「棉棉」住在心情小屋裡：看棉棉的臉說出牠是什麼心情、聽小故事猜角色的感覺、到冷靜小屋吹氣球深呼吸、想一想可以怎麼幫朋友，最後在心情日記裡貼上自己今天的心情，然後去跟爸爸媽媽說。目的是讓小朋友有「心情的詞」和「冷靜的辦法」，而且每一段都把小朋友帶回真人身邊，不是在螢幕上玩很久。

## 給誰
- **2～5 歲**，在台灣，國語為主。
- 兩個難度：
  - **小小**（2～3 歲）：四種基本心情（開心、難過、生氣、害怕），一次只問一個問題，選項兩到四個，點了就唸出來。
  - **大**（4～5 歲）：十四種比較細的心情（見下面「棉棉」），小故事會問「為什麼」，冷靜小屋可以自己選方法。
- 給家長和小朋友**一起玩**：每個小故事之後有一張「家長一起說」的問題卡，給大人問小朋友。一個人玩也可以，但設計是以「大人在旁邊」為主。
- 不連網、不定位、沒有廣告、沒有帳號（和兄弟 APP 一樣）。

### 為什麼做這個（研究找到的）
- 市面上有 Daniel Tiger's Grr-ific Feelings、Sesame「Breathe, Think, Do」、Avokiddo Emotions、Peppy Pals 這些，但**沒有國語的**。
- 2018 年一個研究（Rasmussen 等人）讓 121 個 3～6 歲小朋友玩 Daniel Tiger 的心情 APP 兩個星期，一個月後他們比較會用冷靜的方法，3～4 歲的小朋友也比較認得心情。所以「認心情 + 冷靜方法 + 大人一起」這個組合是有用的。
- 台灣幼兒園課綱的情緒領域分四件事：**覺察與辨識、表達、理解、調節**。這個 APP 的四個遊戲剛好一個對一件事（認表情＝辨識、心情日記＝表達、小故事＝理解、冷靜小屋＝調節）。台北有幼兒園的情緒課特別教比較細的詞（失望、害羞、緊張、得意），所以「大」的心情照這個挑，再加上小朋友在家裡最常有的幾種（無聊、嫉妒、委屈、安心）。
- 設計原則：要小朋友**動腦想**，不是一直點；一個畫面只有幾個可以點的地方；做對的回饋是**結果本身**（棉棉的臉變了、氣球變大了），不是星星和分數；每一段結束都把小朋友**帶回真實生活**（去找爸爸媽媽說、去抱抱）。
- 不做的事：**分享、輪流**這種要有真的人才學得會的事，不在螢幕上教；每次玩很短。

## 練什麼
- **認得心情**：看臉（眉毛、嘴巴、眼淚）知道是哪一種心情，說得出名字。
- **說出心情**：「我今天很開心」「我有一點緊張」，有詞可以用，不用只能哭和叫。
- **懂別人的心情**：東西壞了會難過、等很久會不耐煩、被稱讚會得意，知道「為什麼」。
- **讓自己冷靜**：深呼吸、數到四、抱抱布偶、搥枕頭、喝口水、找大人，六個方法都真的做過。
- **想一想可以怎麼做**：朋友難過的時候可以抱抱、問「你還好嗎」、去找大人。

## 棉棉：會變心情的雲
- 主角是一朵軟軟的雲「**棉棉**」，頭上有一小撮捲捲的雲。棉棉的**形狀和顏色會跟著心情變**，一種心情一個樣子：

| 心情 | 誰學 | 棉棉的樣子 |
|---|---|---|
| 開心 | 小小、大 | 圓圓的暖黃色，彎彎的笑眼，嘴巴張大，旁邊有小星光 |
| 難過 | 小小、大 | 粉藍色，整朵垂下來，眉毛往上揪，兩行眼淚 |
| 生氣 | 小小、大 | 珊瑚紅，邊邊變尖，眉毛往下壓，咬牙，頭上冒煙 |
| 害怕 | 小小、大 | 薰衣草紫，縮小一圈，眼睛睜大，嘴巴張開，兩邊有抖抖的線 |
| 驚訝 | 大 | 薄荷綠，往上拉長，眼睛圓圓的，嘴巴變成「O」，旁邊有「叮」的線 |
| 害羞 | 大 | 粉紅色，臉紅紅的，小小的笑，兩隻小手遮著臉頰 |
| 緊張 | 大 | 黃綠色，眼睛變小，嘴巴歪歪的，旁邊有汗滴 |
| 失望 | 大 | 灰藍色，垂下來，眼皮半垂，嘴巴一條線，旁邊一口嘆氣 |
| 得意 | 大 | 橘色，抬頭挺胸，露牙齒的笑，胸前一顆星，旁邊有星光 |
| 累累的 | 大 | 淡紫色，壓扁一點，眼皮半垂，旁邊打「z z」 |
| 無聊 | 大 | 灰米色，壓扁，眼皮半垂，嘴巴一條線，旁邊三個點「…」 |
| 嫉妒 | 大 | 草綠色，眼睛偷偷看旁邊，眉毛微微往下，嘴巴嘟起來 |
| 安心 | 大 | 薄荷綠，眼睛閉起來，淡淡的笑（冷靜小屋做完就變成這個） |
| 委屈 | 大 | 粉紫色，垂下來，眉毛揪著，嘴巴歪歪的，眼眶一滴淚（還沒哭出來） |

- 臉是**用參數畫的**：眉毛的角度和高度、眼睛張多開（圓、彎、閉、半垂、偷看）、嘴巴的彎度和張不張開、臉紅多少、有沒有眼淚和汗。所以一個角色就能做出全部的心情，中間還可以慢慢變（從生氣變回安心），小朋友看得到「心情是會變的」。
- 朋友「**小雨**」：另一朵雲，頭上一滴小水珠，是小故事和「怎麼辦」裡遇到事情的那個角色。
- 大人：一朵比較大、安心的雲，在「找大人」和「家長一起說」裡出現。
- 不借用小小生活家的紙偶（畫風不一樣），棉棉是這個 APP 自己的。

## 畫面：心情小屋
- 進場是**小屋門口**：棉棉站在門口，臉是「今天的心情」（還沒選就是開心的樣子），上面一顆有臉的太陽。棉棉會打招呼：「你好！今天的心情怎麼樣呢？」
- 下面五個大按鈕，一個按鈕一個房間：**認表情**、**小故事**、**冷靜小屋**、**怎麼辦**、**心情日記**。按鈕上是圖，字只是給大人看。
- 左上角「家長」（鎖頭）進家長關卡；右上角喇叭再唸一次。
- 每個房間都是一個畫面，一次只做一件事；上面一句話（喇叭會唸），中間是棉棉或小故事，下面是兩到四個選項。沒有別的可以點的地方。

## 玩法（五個房間）
### 1. 認表情（辨識）
- 棉棉在台上做一個表情，問：「棉棉現在是什麼心情？」下面兩到四張心情卡（小小的棉棉臉＋字），點一張就唸出那個詞。
- 點對了：棉棉點點頭，說「對，我在生氣」，然後**慢慢變回開心**（回饋就是臉變了，沒有星星）。點錯了：不扣分，棉棉說「我不是難過喔，再看看我的眉毛」，眉毛會跳一下提示。
- 小小：四種基本心情，選項兩個。大：十四種，選項四個（相近的心情不會同時出現，例如難過和委屈），而且會問「你怎麼知道的？」讓大人接著問。
- 以後可以加「換你做做看」：小朋友自己做表情給大人看（螢幕上只提示，不用相機）。

### 2. 小故事：這是什麼心情（理解）
- 一張圖一句話，都是台灣家裡和幼兒園會發生的事，約 20 個：玩具壞掉了、好朋友先回家了、房間暗暗的、被老師稱讚、排隊等很久、阿嬤來了、弄倒牛奶、第一天上學、要打針、生日收到禮物、別人拿走我的車、找不到媽媽、溜滑梯好高、同學不跟我玩、畫的圖被貼在牆上、弟弟拿到新玩具我沒有（嫉妒）、下雨天不能出去玩（無聊）、被誤會是我弄倒的（委屈）、媽媽回來了（安心）……
- 角色（小雨）先是**沒有表情**，頭上一個「？」。問：「小雨現在是什麼心情？」小朋友選一張心情卡。
- **好幾個答案都對**：玩具壞了，難過、生氣、失望都可以。點了一個對的，小雨的臉就變成那個心情，棉棉說：「對，小雨很難過。也可能會生氣喔。」另外對的卡片會標「也可以」，不對的（例如開心）變淡。
- 答完出現「家長一起說」按鈕（見第 6 點）。
- 小小：每個故事只問一次、兩個選項。大：四個選項，答完多問一句「如果是你，你會怎麼樣？」

### 3. 冷靜小屋（調節）
六個冷靜的方法，每一個都是一個小小的活動，**真的要做動作**，做的時候棉棉也跟著一起做，做完棉棉的臉從緊張變安心：
| 方法 | 怎麼玩 | 聲音 |
|---|---|---|
| 吹氣球深呼吸 | **按住**螢幕慢慢吸氣，氣球慢慢變大（按四秒）；放開慢慢吐氣，氣球飄起來。做三次。下面有一條呼吸的波浪線跟著走。 | 吸氣聲、吐氣聲、氣球飄走的小聲音 |
| 數到四 | 四顆雲一顆一顆點，每點一顆唸一個數字，點完棉棉說「我冷靜下來了」。 | 唸 1、2、3、4，柔和的鈴聲 |
| 抱抱布偶 | 把小熊拖到棉棉身上（或點小熊），抱住的時候慢慢搖，心跳聲慢下來。 | 慢慢的心跳、軟軟的「嗯～」 |
| 搥枕頭 | **用力點枕頭**為主，枕頭扁下去又彈回來，棉棉的紅色一下一下退掉；搖手機也可以（為輔，家長模式可以關掉）。沒有「打人」，只有枕頭。 | 噗、噗的悶聲 |
| 喝口水 | 把水杯拖到棉棉嘴邊，咕嚕咕嚕，身上的汗滴不見。 | 倒水、喝水聲 |
| 找大人 | 點一下，大人雲走過來牽起棉棉。然後 APP 說：「**現在換你去找大人**。」這一個會直接結束這一段。 | 腳步聲、溫柔的「我在這裡」 |
- 小小：只開「吹氣球」「抱抱布偶」「找大人」三個，而且生氣的題目答完會自動帶到冷靜小屋。大：六個都可以自己選，做完問「哪一個最有用？」記在日記裡。
- 冷靜小屋也可以**從家長模式一鍵打開**，而且**不限時間**：小朋友真的在生氣的時候，家長拿出手機直接到冷靜小屋。

### 4. 怎麼辦（想一想可以做什麼；0.1 就做）
- 延續小故事：小雨難過了，問「你可以怎麼做呢？」三個選項都是**好的做法**（沒有錯的）：抱抱小雨、問「你還好嗎？」、去找大人。點一個就看到結果：棉棉抱住小雨，小雨的臉慢慢好起來。
- 也有「自己」的版本：「你很生氣，可以怎麼做？」選項是冷靜小屋的方法，點了就直接過去做。
- **不教分享和輪流**：那些留給真的朋友一起練，畫面下面會提醒大人（「分享和輪流，留給真的朋友一起練」）。

### 5. 心情日記（表達）
- 每次玩的最後（或家長任何時候打開），問：「今天，你的心情是？」小朋友點一朵雲。小小四朵，大十四朵（三排）。
- 點完棉棉變成那個心情，說：「今天你是開心的！去說給爸爸媽媽聽。」有一個大按鈕「**說給爸爸媽媽聽**」，按了 APP 唸一句給大人聽的話，然後回小屋、結束這一次。
- 下面一排是這一個星期：每天一朵小雲，今天亮亮的，還沒到的日子是虛線。小朋友看得到「心情每天不一樣」。
- 家長模式看得到每一天選了什麼、最常選的是什麼、哪一天用了冷靜小屋。

### 6. 家長一起說（給大人的問題卡；每個故事後都出現，可以跳過）
- 每個小故事答完、每次日記選完，都有一張卡**給大人看**（上面標「這一頁給大人看」）：
  - **問問孩子**：「你有沒有東西壞掉的時候？那時候你是什麼心情？」
  - **可以一起說**：「東西壞掉會難過，也會生氣。難過的時候可以說出來、可以抱抱，或是請大人幫忙。」
  - 小提醒：「先聽孩子說，不用急著教。」
- 有「念出來」（喇叭）、「下一個問題」、「回小屋」。大人不想看可以直接跳過，家長模式也可以整個關掉。
- 問題卡大約 40 張（每個故事兩張、每種心情一張、冷靜方法一張）。

## 一次玩的流程（大約 8～10 分鐘）
小屋打招呼 → 認表情 2 題 → 小故事 1 個（＋怎麼辦）→ 家長一起說 → 冷靜小屋 1 個 → 心情日記 → 「說給爸爸媽媽聽」→ 結束。
每個房間也可以從小屋直接進去，不一定要照順序。

## 偶爾會發生的事
- **棉棉自己有心情**（一次玩 1～2 次）：進小屋的時候棉棉可能在難過、害怕或緊張（「我今天要去打針，好緊張」）。小朋友可以問牠怎麼了（點牠）、幫牠選一個冷靜的方法。小朋友照顧棉棉，就是在練「注意到別人的心情」。
- **天氣跟著心情**：小屋的天空會跟今天的心情變（開心是太陽、難過是小雨、生氣是熱熱的紅太陽、安心是晚霞），但晚上和雨天都畫得暖暖的，不嚇人。
- **棉棉的話**：每天第一次打開說一句不一樣的話（「昨天你說你很累，今天有睡飽嗎？」用日記的紀錄來說）。

## 獎勵：沒有星星，只有小屋變溫暖
- 做對的回饋就是結果本身：棉棉的臉變了、氣球變大了、小雨好起來了。沒有分數、沒有星星、沒有排名。
- 唯一會累積的是**小屋**：寫日記的日子，小屋的窗戶多一盞燈、門口多一盆花、屋頂多一朵小雲（一個星期一樣），家長和小朋友看得到「我們有一直在說心情」。沒寫的日子不會扣掉。
- 冷靜小屋做完，棉棉會給小朋友一個抱抱（畫面上棉棉貼過來，有軟軟的聲音），這就是獎勵。

## 每次玩多久
- 家長設定，**預設 15 分鐘**，可以選 5／10／15／20／30 分鐘。時間到了棉棉打哈欠、天空變成晚霞、小屋的燈亮起來，APP 說：「**換你去做了！去跟爸爸媽媽說說你今天的心情。**」要家長解開或等一個小時才能再玩。
- 冷靜小屋**不受時間限制**：家長從家長模式打開的冷靜小屋隨時可以用，因為那是真的需要的時候。

## 家長模式（要過家長關卡）
- 年齡（小小／大）、每次玩多久（5／10／15／20／30）、要哪些心情（可以先關掉害怕）、要不要家長一起說的卡片、搥枕頭要不要搖手機。
- 看心情日記：每一天選了什麼、這個月最常選的、用過哪些冷靜方法、哪一個最常用。只有這台手機看得到，不會傳出去。
- 一鍵打開冷靜小屋（不限時）。
- 聲音、唸出來、英文（以後）。
- 第二個小朋友（兄弟姊妹各一本日記，0.2）。
- 以後的完整版購買只在這裡。

## 畫風：棉花糖雲朵風（只做一種；草圖見 `docs/mockups/0_畫風選擇.png` 的 A）
每樣東西都是軟軟圓圓的一塊，像棉花糖和雲：霧面、**沒有框線**、淡淡的粉彩色（薰衣草紫、奶油黃、粉紅、薄荷綠、粉藍）、左上方來一點柔和的光，下面一點淡淡的影子。棉棉本身就是一朵雲，整個 APP 的按鈕、房子、太陽都是同一種軟軟的感覺，看起來很安全、很好抱，剛好配心情的主題。

和八個兄弟 APP 都不一樣：畫畫小鎮是粗黑框的貼紙（這裡**完全沒有框線**）；字母寵物是水彩繪本（這裡沒有筆觸和紙紋，是光滑的霧面）；動物小餐廳是黏土（黏土有指紋和硬邊，棉花糖更軟、邊邊是霧的）；小卡認天下是寫實和簡單色塊（這裡是立體的軟塊，不是平塗）；想一想樂園是動畫片、剪紙、積木（都有框線或硬邊）；眼尖尖是等角小模型、孔版印刷、粗蠟筆（都有紋理或透視）；迷宮是羊毛氈、像素、果凍糖果（羊毛氈有毛邊、果凍是透明亮亮的，棉花糖是不透明霧面的）；小小生活家是立體書（紙片有厚度和銳利的邊）。棉花糖雲朵風的特徵是「霧面、無框、漸層、圓」，和上面每一種都分得開。

（草圖裡的 B 氣球玩具風、C 粉筆黑板風只是當時的候選，沒有選。）

## 聲音
- **背景音樂**：很慢、很輕的搖籃曲式音樂（木琴、鐘琴、軟軟的墊子聲），小屋一首、冷靜小屋一首更慢的、小故事一首輕一點的。
- **呼吸的聲音**：吸氣（慢慢變大的風聲）、吐氣（慢慢變小）、氣球飄走的小聲音。按住的時候聲音跟著手指走，放開就吐氣。
- **每一種心情一個小聲音**：開心是向上的兩個音、難過是向下的兩個音、生氣是低低的「哼」、害怕是抖抖的小音、驚訝是「叮」、害羞是小小的笑聲、緊張是快快的心跳、失望是嘆氣、得意是小小的號角、累累的是打哈欠、無聊是拖長的「嗯～」、嫉妒是「哼！」短短一聲、安心是長長的「呼～」、委屈是小小的抽泣。點心情卡就聽到，不用看字也知道是哪一個。
- **動作音效**：點按鈕（軟軟的「噗」）、氣球變大、枕頭「噗噗」、喝水、小熊抱抱「嗯～」、小屋燈亮起來「叮」。
- 全部用程式合成（numpy），沒有別人的素材。TTS 唸全部的字：題目、心情的名字、棉棉說的話、給大人的問題卡。

## 技術（和兄弟 APP 一樣）
- Flutter 3.47.8、Riverpod、flutter_svg、audioplayers、flutter_tts；存檔是一個 JSON 檔（`app/lib/core/store.dart`），沒有 drift。
- 點、按住、拖都用原始的手指事件（`Listener`）；「搥枕頭」以用力點為主，搖手機（加速度感應器，不用權限）為輔，家長模式可以關掉。
- 圖用 Python 畫 SVG（`design/art/`：`kit.py` 棉花糖畫法、`mianmian.py` 棉棉的身體和參數臉、`scenes.py` 小故事的場景、`props.py` 氣球小熊枕頭水杯、`icon.py` 圖示；`build.py all` 產生和檢查）。棉棉的臉在 APP 裡**不是一張一張圖**，是用 CustomPainter 照參數畫的，才能慢慢變。
- 聲音用 numpy 合成（`design/sounds/make_sounds.py`）。
- 資安和兄弟 APP 一樣：不接受別的 APP 傳來的頁面（`flutter_deeplinking_enabled` 關掉、`overridePlatformDefaultLocation`）、家長模式只能從家長關卡進去（`ParentPass`）、不要任何權限。日記只存在手機裡。

  - GitHub 專案：`APP_Kids_Feelings`（`https://github.com/yaufan/APP_Kids_Feelings`，還沒開；和兄弟 APP 一樣先公開，設計完整後再改私有）。
  - APK：`feelings-house-<版本>-arm64.apk`（另外有 armv7、x86_64）。
  - 簽章：環境變數 `FEELINGS_HOUSE_KEYSTORE`（和兄弟 APP 同一把測試金鑰，別名 `kidspaint`；Secrets 名稱照兄弟 APP：`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`）。

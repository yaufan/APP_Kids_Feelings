# 心情小屋的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，四首曲子都是為這個 APP 新寫的。給 2～5 歲的小朋友，所以**很慢、很軟、像搖籃曲**；沒有刺耳或突然的聲音，「生氣」「嫉妒」也只是短短低低的一聲「哼」。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、接頭）檢查的；請在手機上聽聽看，覺得哪個不像、不好聽再改。

## 怎麼產生
```
python3 design/sounds/make_sounds.py                # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py tap hug        # 只重做這幾個
python3 design/sounds/make_sounds.py preview 試聽.m4a # 全部連在一起的試聽檔（要 ffmpeg）
```
- 亂數用固定的種子（照聲音的名字），每次跑出來的檔案都一模一樣。
- 程式會檢查：音效不超過 1.5 秒（呼吸 4.3 秒）、不會太大聲、背景音樂 18～30 秒而且頭尾接得起來、資料夾裡沒有別的檔案、全部不超過 8 MB。
- 格式：WAV、單聲道、16 位元；背景音樂 16,000 Hz，音效 22,050 Hz。

## 背景音樂
| 檔案 | 用在哪裡 | 聽起來 |
|---|---|---|
| `music_home` | 小屋、認表情、心情日記 | 音樂盒的搖籃曲，C 大調，每分鐘 66 拍 |
| `music_story` | 小故事、怎麼辦 | 卡林巴（拇指琴），輕一點，G 大調，80 拍 |
| `music_calm` | 冷靜小屋 | 最慢，長長的和弦像呼吸一樣起伏，D 大調，52 拍 |
| `music_rest` | 休息時間 | 很輕的鐘琴，56 拍 |

## 每種心情一個聲音（點心情卡就聽到）
| 檔案 | 心情 | 聲音 |
|---|---|---|
| `feel_happy` | 開心 | 往上的兩個音 |
| `feel_sad` | 難過 | 往下的兩個音 |
| `feel_angry` | 生氣 | 低低的「哼」 |
| `feel_scared` | 害怕 | 抖抖的小音 |
| `feel_surprised` | 驚訝 | 「叮！」往上彎 |
| `feel_shy` | 害羞 | 小小的笑聲 |
| `feel_nervous` | 緊張 | 快快的心跳 |
| `feel_disappointed` | 失望 | 嘆一口氣 |
| `feel_proud` | 得意 | 小小的號角 |
| `feel_tired` | 累累的 | 打哈欠 |
| `feel_bored` | 無聊 | 拖長的「嗯～」 |
| `feel_jealous` | 嫉妒 | 短短一聲「哼！」 |
| `feel_calm` | 安心 | 長長的「呼～」 |
| `feel_wronged` | 委屈 | 小小的抽泣 |

## 動作的聲音
| 檔案 | 什麼時候 |
|---|---|
| `tap` | 點按鈕（軟軟的「噗」） |
| `pop` | 選項跳出來 |
| `chime` | 柔和的鈴聲（問你還好嗎、數完） |
| `right` | 選到對的心情 |
| `try` | 選到不對的：溫柔的「嗯？」 |
| `whoosh` | 進房間 |
| `ding` | 小屋的燈亮起來、日記寫好 |
| `breath_in`、`breath_out` | 吹氣球：按住吸氣（風聲變大）、放開吐氣（變小），各 4 秒 |
| `float` | 氣球飄走 |
| `count_1`～`count_4` | 數到四，一顆雲一個音，越來越高 |
| `hug` | 小熊抱抱的「嗯～」 |
| `heartbeat` | 抱抱時慢下來的心跳 |
| `thump` | 搥枕頭「噗」 |
| `pour`、`gulp` | 倒水、喝水 |
| `steps` | 大人走過來 |
| `sparkle` | 棉棉的臉變好了、說好棒 |
| `clap` | 一起拍拍手 |
| `page` | 翻到下一張卡片 |
| `night` | 休息時間到了 |
